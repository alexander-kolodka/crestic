# 📄 Config Example

```bash
crestic config.example
```

Print a comprehensive example configuration file to stdout, with comments documenting the available options.

## Examples

```bash
# Print to terminal
crestic config.example

# Save as a starting config
crestic config.example > crestic.yaml
```
